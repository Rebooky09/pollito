# Para mi pollito 💛

Página web romántica con galaxia, estrellas, flores amarillas y un pollito.

## Publicarla gratis con GitHub Pages

1. Crea un repositorio público llamado `para-mi-pollito`.
2. Sube `index.html`.
3. Ve a Settings → Pages.
4. En Source selecciona `Deploy from a branch`.
5. Branch: `main` y carpeta `/ (root)`.
6. Guarda y espera unos minutos.

Tu enlace será parecido a:
https://TU-USUARIO.github.io/para-mi-pollito/
